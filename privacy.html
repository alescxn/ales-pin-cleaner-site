Privacy Policy

Last updated: November 24, 2026

Information We Access

Ales Pin Cleaner accesses the Pinterest boards and Pins of its owner through the Pinterest API.

Access Token

The Pinterest API access token is entered locally by the application owner. It is not stored on this website.

Data Usage

The application uses Pinterest data only to review Pins saved on the owner's boards. It does not sell or share this data with third parties.

Pin Removal

No Pin is removed without the owner's manual selection and explicit confirmation.

Contact

For questions about this application, please contact the application owner through the project's GitHub repository.

This project is independent and is not affiliated with Pinterest.
