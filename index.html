Ales Pin Cleaner

A personal tool for reviewing saved Pins on my own boards.

About the Application

This application helps me review Pins saved to my own Pinterest boards. I can manually select Pins for removal. No Pins are deleted without my explicit confirmation.

Privacy Policy

This website does not collect or store personal information.

The local application uses an access token supplied by its owner to communicate with the Pinterest API. The token is not stored by this website.

This application is for personal use only and is not affiliated with Pinterest.
